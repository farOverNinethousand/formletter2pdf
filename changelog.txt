====================================================================================
formletter2pdf - change log
====================================================================================

============================
v2.11 - October 2026
============================

- the dialog opens immediately; the data source is only read (with a cancellable progress bar) when the preview is refreshed or the export is started
- the dialog can be resized (Windows only) and remembers its size until Word is closed;the preview list has fixed width columns and scrolls horizontally for long file names
- a detail line below the preview list shows the complete file name and note of the selected row
- the dialog and all messages are available in English and German: the language of Word is used at the start (setting DefaultLanguage in the module), and a drop-down at the top right of the dialog changes all texts at once; all texts are in a table at the end of the module formletter2pdf
- the progress shows the remaining time (scan and export): the export starts with an estimate of 0.5 seconds per page of the main document (setting DefaultSecondsPerPage), which is adjusted live with the measured times
- the result message shows the duration of the export
- the label "Folder name" is called "Folder name pattern"
- the link below the logo points to github.com/farOverNinethousand/formletter2pdf; the old website formletter2pdf.com is a second link next to it
- new setting CustomDefaultFilenamePattern (default empty): an own default file name pattern which is shown in the dialog and does not trigger the error for the shipped default pattern
- added the section "Messages" above the create button with three settings: confirm dialog before writing files (always, only when warnings exist, never), result message after the export (always, only when warnings exist, never) and opening the output folder (ask, open folder, do not open folder; Windows only). Errors are always shown.
- added a check box "Enable quick scan" which limits the scan to the first 2 records (the export always reads all records)
- added an error message if the file name pattern shipped with formletter2pdf is still used when scanning or exporting, because its fields normally do not exist in a data source (an own default pattern in the module is accepted)
- the file types are shown as check boxes, so all of them are always visible without scroll bar
- Word is no longer hidden during the export, so the progress bar and the cancel button stay visible
- added an option to stop reading the data source and the export at the first record where ALL fields are empty (speeds up data sources with many empty rows); without this option empty records are skipped
- the button "Export files" (german: "Export starten") shows the number of files after a scan ("Export 12 files")
- messages and preview rows about an early stop show the total number of records (e.g. "record 17/150")
- file types with the same file extension are counted only once in the preview; selecting several of them is rejected with an error which lists them, before the data source is read
- new errors before anything is written (Windows): no write access to the storage location, file paths longer than 259 characters, file names reserved by Windows (CON, NUL, COM1, ...); the preview marks such file names
- all checks of the settings (file types, file name pattern, field, storage location, folder name) are made before the data source is read or any file is written; new: error if the storage location does not exist
- the "Cancel" button is called "Close"; while the export runs the export button is called "Abort export" and stops the export
- fixed: the controls at the bottom (e.g. the donation text) were cut off by the resize border of the dialog
- the scan button becomes "Abort scan" while the data source is read, and it is greyed out while the export runs
- added a progress bar; the export can be cancelled with the cancel button
- added an option to write a log file into the folder with the generated files
- the dialog shows how many files will be created and a preview of all file names
- the form letters can be saved in several file types at once (multi selection list instead of single choice, default: pdf)
- added an option to stop scanning the data source and the export at the first record where a chosen data source field is empty; the form letters before are saved and a warning is shown
- added handling of already existing files: ask, overwrite, skip or save with number; the folder may now already exist
- fixed: dynamic fields were updated in the main document instead of the created document
- fixed: after a run the mail merge was limited to the last record
- fixed: records excluded in the recipient list were exported anyway
- fixed: Rich Text Format was saved as plain text with the extension .rte (now .rtf)
- fixed: "Web Page (.htm)" was not preselected as stored file type
- fixed: the counter in the success message could be wrong when empty records were skipped
- fixed: cancelling the print dialog still printed all further files
- fixed: Windows Explorer did not open folders with spaces in the path reliably
- fixed: file names ending with a dot or space, containing control characters or being too long
- added Option Explicit and declared all variables
